Admin panels for FastAPI, written in Python.

Describe your forms and tables in a few Python classes. Tungsten gives you a complete, good-looking admin panel with search, filters, actions, charts, logins and roles. No HTML, no JavaScript, no build step.

Built on tools you know

Fits into the app you already have

Tungsten mounts inside your FastAPI app and works with your SQLAlchemy models. Pages are rendered on the server with Jinja, made interactive with HTMX and Alpine.js, and styled with Tailwind. The CSS comes prebuilt, so you never run npm.

  1. Installpip install tungsten-admin
  2. Describeclass ProductResource(Resource): ...
  3. Mountpanel.mount(app)
  4. Sign intungsten make:user
