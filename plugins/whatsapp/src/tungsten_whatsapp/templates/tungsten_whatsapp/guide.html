{% call note('Before you start') %}
  • Meta's official WhatsApp API. Best for a business number that many people message.
  • A phone number that is not on the WhatsApp app. To use a number that is, delete its WhatsApp account on the phone first (back up chats). A new SIM is easiest.
  • This panel online on a public https address, so replies can come in.
  • A card, or UPI funds in India, for Meta's message charges.

{% endif %} {% endcall %} {% call part(1, 'Create a Meta app', 'https://developers.facebook.com/apps/creation/', 'Meta for Developers') %}
  • Sign in at developers.facebook.com. The first time, press Get started and confirm your phone and email.
  • Press Create app, type a name and your email, then Next.
  • Use case: pick Connect with customers through WhatsApp. Pick your business portfolio (or make one), then Create app.
    • {% endcall %} {% call part(2, 'Add your phone number') %}
  • In the app open Use cases, then Customize next to WhatsApp, then API Setup (older apps: WhatsApp, API Setup).
  • In From, press Add phone number. Type your business name and category, then your number, and enter the code Meta sends by SMS or call.
  • Pick your number in From. Copy its Phone number ID and the WhatsApp Business Account ID (Meta may call it Messaging account ID).
  • Meta also gives a free test number. It is fine for a first try, but switch to your own number for real use.
    • {% endcall %} {% call part(3, 'Make a permanent access token', 'https://business.facebook.com/latest/settings', 'Business settings') %}
  • In Business settings open Users, then System users. Press Add, give a name, pick role Admin.
  • Press Assign assets. Give it Full control of your app and of your WhatsApp account.
  • Press Generate token. Pick your app, expiry Never, and tick whatsapp_business_messaging and whatsapp_business_management. Copy the token right away; Meta shows it once.
  • Do not use the temporary token from API Setup. It stops working within hours.
    • {% endcall %} {% call part(4, 'Copy the App secret') %}
  • In your app open App settings, then Basic. Next to App secret press Show and copy it. It proves that messages really come from Meta.
    • {% endcall %} {% call part(5, 'Fill this page') %}
  • Close this guide. In How to send pick Cloud API (official).
  • Paste the Phone number ID, WhatsApp Business Account ID, Access token and App secret, then press Save changes.
    • {% endcall %} {% call part(6, 'Register your number') %}
  • Press More, then Register number, and type a 6-digit PIN. Meta needs this once before your own number can send.
  • If two-step verification is already on for the number, type that PIN. Keep the PIN safe; Meta asks for it again if you move the number.
    • {% endcall %} {% call part(7, 'Connect the webhook') %}
  • In your app open Use cases, Customize next to WhatsApp, then Configuration (older apps: WhatsApp, Configuration).
  • Paste these two and press Verify and save: {{ copy('Callback URL', webhook_url) }} {{ copy('Verify token', verify_token) }}
  • Under Webhook fields, press Subscribe next to messages.
    • {% endcall %} {% call part(8, 'Publish the app') %}
  • In App settings, Basic, add a Privacy Policy URL (a page on your website), a category and an icon, then save.
  • Left menu: Publish, then Go live. Some messages are not sent to apps that are still in development.
    • {% endcall %} {% call part(9, 'Add a payment method', 'https://business.facebook.com/latest/billing_hub/payment_methods/', 'Billing') %}
  • In Billing, pick your WhatsApp account and add a card. In India you can add funds by UPI instead.
  • Choose with care: Meta does not let you switch between prepaid (UPI) and card later.
    • {% endcall %} {% call part(10, 'Check and test') %}
  • Press Check connection. It checks your number and makes sure replies come in here.
  • From your own phone, send "Hi" to the business number. It shows in WhatsApp chats.
  • Press Send a test and send a message back to your phone.
    • {% endcall %} {% call part(11, 'Templates, to start chats', 'https://business.facebook.com/latest/whatsapp_manager/message_templates', 'WhatsApp Manager') %}

  • In WhatsApp Manager, Message templates, press Create template. Use number variables like {{ '{{1}}' }} for the name.
  • When Meta approves it, press More, then Sync templates. It now shows in the WhatsApp button on leads.

    {# ---------------------------------------------------------------- WhatsApp Web #}
    {% call note('Read this first', 'warning') %}

    WhatsApp Web mode is not an official API. It links your own WhatsApp number, like WhatsApp Web on a laptop. WhatsApp may block numbers that send bulk or unwanted messages, so use it to talk with people who expect your messages.

    You need a Linux server with Docker (a VPS with 2 CPU and 4 GB memory is safe). Shared cPanel hosting cannot run it, but this panel can stay there.

    {% endcall %} {% call part(1, 'Install the WAHA gateway', 'https://waha.devlike.pro/blog/waha-on-docker/', 'WAHA docs') %}
  • Log in to your server with SSH and install Docker: {{ code('curl -fsSL https://get.docker.com | sh') }}
  • Download WAHA's setup file: {{ code('mkdir waha && cd waha\nwget -O docker-compose.yaml https://raw.githubusercontent.com/devlikeapro/waha/refs/heads/core/docker-compose.yaml') }}
  • Open docker-compose.yaml (for example nano docker-compose.yaml) and change the line image: devlikeapro/waha-plus to image: devlikeapro/waha.
  • Make the passwords and the API key, then start it: {{ code('docker compose run --no-deps -v "$(pwd)":/app/env waha init-waha /app/env\ndocker compose up -d') }}
  • The first line prints Use this API key in the x-api-key header and a key under it. Copy that key; you paste it here soon.
  • This setup keeps WAHA private on the server, keeps your phone linked after restarts, and starts again by itself.
    • {% endcall %} {% call part(2, 'Let this panel reach WAHA') %}
  • Same server as this panel: the Gateway URL is http://127.0.0.1:3000.
  • Another server (for example this panel on cPanel): point a subdomain such as waha.yourbusiness.in at the server, and put Nginx with a free Let's Encrypt certificate in front of port 3000. The Gateway URL is then https://waha.yourbusiness.in.
  • Never open port 3000 itself to the internet. The API key goes with every call.
  • WAHA also calls this panel when a message comes in, at the address below, so this panel must be reachable from the WAHA server: {{ copy(None, web_webhook_url) }}
    • {% endcall %} {% call part(3, 'Fill this page') %}
  • Close this guide. In How to send pick WhatsApp Web (linked phone).
  • Type the Gateway URL and the API key. Leave the session name as default. Press Save changes.
  • The Link phone button now shows at the top.
    • {% endcall %} {% call part(4, 'Link your phone') %}
  • Open this page on a computer, not on the phone you are linking.
  • Press Link phone. On the phone open WhatsApp, then the ⋮ menu (iPhone: Settings), Linked devices, Link a device, and scan the code.
  • The code changes every 20 to 60 seconds. If it stops working, close the popup and press Link phone again.
  • Press I have scanned it. The status turns Linked.
    • {% endcall %} {% call part(5, 'Test it') %}
  • From a different phone, send a message to your WhatsApp number. It shows in WhatsApp chats, and becomes a lead if "New chats become leads" is on.
  • Press Send a test to send one back.
    • {% endcall %} {% call note('Keep it working') %}
    • Open WhatsApp on the main phone at least once every 14 days, or WhatsApp logs out all linked devices.
    • A number can have 4 linked devices. If linking fails, remove an old one under Linked devices.
    • Messages you type on the phone itself do not show here.
    • To stay safe: reply to people who wrote first, keep first messages short and personal, and do not send the same text to many new numbers. If sending to new numbers fails with error 463 or 475, WhatsApp is limiting you for a while. Wait; linking again does not help.
